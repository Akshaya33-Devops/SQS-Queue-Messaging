

# 📦 Project 38: SQS Queue Messaging

## 🎯 Purpose

This project is used to send and receive messages using AWS SQS.
SQS stores messages safely until they are processed.

---

## 🧠 What I learned

* Create SQS queue
* Send message
* Receive message

---

## 🪜 Steps

### 1️⃣ Create Queue

* Go to AWS Console
* Search **SQS**
* Click **Create Queue**
* Choose **Standard Queue**
* Name it: `my-first-queue`
* Click **Create**

---

### 2️⃣ Send Message

* Open the queue
* Click **Send and receive messages**
* Type message: `Hello Cloud Engineer`
* Click **Send message**

---

### 3️⃣ Receive Message

* Click **Poll for messages**
* View the message

---

## 📌 Result

Message is successfully sent and received using SQS.
